# PharmaVision Egypt 💊
### رؤية سوق الدواء في مصر

## Project Overview
PharmaVision Egypt is a Data Analytics graduation project developed as part of the Digital Egypt Pioneers Initiative (DEPI).

The project aims to provide an analytical overview of the Egyptian pharmaceutical market by exploring pharmaceutical companies, drug products, prices, availability, therapeutic categories, and medical information.

## Project Objectives
- Analyze pharmaceutical companies operating in Egypt.
- Explore and compare drug prices and products.
- Analyze medicine availability.
- Identify therapeutic categories and drug usage.
- Explore product warnings and medical information.
- Build interactive dashboards to support data-driven insights.

## Dataset
The project explores pharmaceutical product data, including:
- Company Names
- Drug Names
- Current and Previous Prices
- Product Availability
- Units
- Medical Uses
- Warnings

## Tools & Technologies
- Microsoft Excel
- Power Query
- Data Cleaning & Transformation
- Data Modeling
- DAX
- Microsoft Power BI

## Expected Deliverables
- Cleaned and structured dataset.
- Pharmaceutical market analysis.
- Company and product comparisons.
- Interactive Power BI dashboard.
- Business and market insights.
